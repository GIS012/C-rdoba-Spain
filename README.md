# Córdoba, Spain - Data Portal

A beautiful, interactive web page showcasing comprehensive data about Córdoba, Spain - the historic UNESCO World Heritage city in Andalusia.

![Córdoba Spain Web Page](https://github.com/user-attachments/assets/b3d53394-0012-4b2a-9655-b0857250a39e)

## Features

### 🏛️ Rich Data Display
- **Population Statistics**: Current demographics and population data
- **Geographic Information**: Area, elevation, and location details  
- **Historical Context**: Founded by Romans in 152 BC as Corduba
- **Climate Data**: Average temperatures and weather information

### 🎨 Interactive Elements
- **Data Explorer**: Switch between different categories (Demographics, Tourism, Culture, General)
- **Animated Progress Bars**: Visual representation of economic indicators
- **Hover Effects**: Enhanced user experience with smooth animations
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices

### 📊 Comprehensive Information
- **UNESCO World Heritage Sites**: Detailed information about Mezquita-Catedral, Historic Centre, and Alcázar
- **Economic Indicators**: GDP, tourism revenue, and employment statistics
- **Tourism Data**: Visitor numbers, hotel occupancy, and attraction details
- **Cultural Heritage**: Museums, monuments, and cultural events

## How to Run

### Option 1: Simple File Opening
1. Download all files (`index.html`, `styles.css`, `script.js`)
2. Open `index.html` in any modern web browser

### Option 2: Local Web Server (Recommended)
```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js (if you have it installed)
npx serve .

# Then open http://localhost:8000 in your browser
```

### Option 3: Live Server (VS Code)
1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html` and select "Open with Live Server"
